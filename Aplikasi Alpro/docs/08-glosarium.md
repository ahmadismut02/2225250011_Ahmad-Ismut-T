# 08 — Glosarium

## Istilah Pendidikan

| Istilah | Arti |
|---|---|
| **Beban kognitif (cognitive load)** | Jumlah usaha mental yang dipakai memori kerja saat belajar |
| **Beban intrinsik (IL)** | Beban yang berasal dari kompleksitas materi itu sendiri |
| **Beban ekstrinsik (EL)** | Beban tambahan akibat cara penyajian yang kurang baik; harus dikurangi |
| **Beban germane (GL)** | Usaha mental yang membangun pemahaman (skema); harus didorong |
| **Skema** | Struktur pengetahuan di memori jangka panjang |
| **Worked example** | Contoh soal yang diselesaikan langkah demi langkah |
| **Fading** | Mengurangi bantuan secara bertahap dari contoh lengkap ke soal mandiri |
| **Scaffolding** | Bantuan sementara yang dikurangi seiring meningkatnya kemampuan |
| **Self-explanation** | Siswa menjelaskan sendiri alasan sebuah langkah |
| **Spaced repetition** | Mengulang materi dengan jarak waktu yang makin panjang |
| **Expertise reversal effect** | Bantuan yang berguna bagi pemula bisa menghambat siswa yang sudah mahir |
| **Miskonsepsi** | Pemahaman keliru yang konsisten (mis. 2³ = 6) |
| **CP / TP** | Capaian Pembelajaran / Tujuan Pembelajaran (Kurikulum Merdeka) |
| **Fase D** | Jenjang kelas 7–9 pada Kurikulum Merdeka |
| **N-gain** | Ukuran peningkatan skor pre-test ke post-test, dinormalisasi |
| **Skala Paas** | Skala 1–9 untuk mengukur usaha mental subjektif |
| **SUS** | System Usability Scale — kuesioner 10 butir untuk mengukur kemudahan penggunaan |
| **Literasi matematika** | Kemampuan bernalar matematis serta merumuskan, menerapkan, dan menafsirkan matematika dalam konteks nyata (PISA) |
| **Numerasi (AKM)** | Kemampuan berpikir menggunakan konsep, prosedur, fakta, dan alat matematika untuk menyelesaikan masalah sehari-hari dalam berbagai konteks |
| **AKM** | Asesmen Kompetensi Minimum — bagian Asesmen Nasional yang mengukur literasi membaca dan numerasi |
| **PISA** | Programme for International Student Assessment (OECD) |
| **Pemodelan matematika** | Proses mengubah situasi nyata menjadi model matematika, menyelesaikannya, lalu menafsirkan dan memeriksa hasilnya |
| **Model matematika** | Representasi matematis dari situasi nyata, misalnya `B = 3 × 2ⁿ` |
| **Stimulus** | Teks, tabel, atau infografis yang menjadi dasar beberapa soal literasi |
| **Proses kognitif AKM** | Pemahaman, Penerapan, Penalaran |
| **Konteks AKM** | Personal, Sosial budaya, Saintifik |
| **Pilihan ganda kompleks** | Soal pilihan dengan lebih dari satu jawaban benar |

## Istilah Matematika

| Istilah | Arti |
|---|---|
| **Basis** | Bilangan yang dikalikan berulang (pada 2⁵, basisnya 2) |
| **Pangkat / eksponen** | Banyaknya perkalian berulang (pada 2⁵, pangkatnya 5) |
| **Faktorisasi prima** | Menguraikan bilangan menjadi perkalian bilangan prima (8 = 2³) |
| **Notasi ilmiah** | Penulisan a × 10ⁿ dengan 1 ≤ a < 10 |

## Istilah Teknis

| Istilah | Arti |
|---|---|
| **PRD** | Product Requirements Document — dokumen kebutuhan produk |
| **MVP** | Minimum Viable Product — versi terkecil yang sudah berguna |
| **MoSCoW** | Prioritas Must / Should / Could / Won't |
| **PWA** | Progressive Web App — web yang bisa dipasang & berjalan offline |
| **Capacitor** | Alat untuk membungkus aplikasi web menjadi aplikasi Android |
| **Offline-first** | Aplikasi dirancang tetap berfungsi tanpa internet |
| **IndexedDB / Dexie** | Basis data di browser / pustaka untuk memakainya |
| **KaTeX** | Pustaka untuk menampilkan rumus matematika |
| **ADR** | Architecture Decision Record — catatan keputusan arsitektur |
| **CI** | Continuous Integration — pengujian & build otomatis setiap perubahan |
| **WCAG** | Pedoman aksesibilitas konten web |
| **Definition of Done** | Daftar syarat agar sebuah pekerjaan dianggap selesai |
| **Edge Function** | Fungsi server kecil (Supabase) yang dipakai sebagai perantara aman ke layanan luar, misalnya Claude API |
| **Structured output** | Keluaran AI yang dipaksa mengikuti skema JSON tertentu agar dapat diproses program |
| **OCR** | Optical Character Recognition — membaca teks dari foto |
| **Prompt injection** | Upaya menyisipkan perintah di dalam input agar AI berperilaku di luar aturan |
